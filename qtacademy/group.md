# 量潮实训基地飞书社群管理章程（提纲）

状态：提纲草稿。**【已定】** = 创始人口述或仓内事实已确定，**【待定】** = 空位。
写法按章程惯例：每条能执行、能违反、能检查；比喻（门派、公司式类比）只作理解，进条款前必须还原成具体动作。

## 第〇章 范围与定位

- 【已定】本章程是**社区层面的总章程**：定公司与实训基地在社群上的分工与合作，**不定社群内部细则**
- 【已定】社群定位：实训基地**外围的社区组织**，本身有很强的交流作用，公司成员也在群内活跃
- 【已定】服务三条线：课堂、众包、招聘
- 【已定】社群内部细则（日常管理、清理办法等）由**基地成员自己制定**，本章程只给框架
- 不归本章程管、写定前要在这一节列全的：
  - 邀请链接怎么取、寿命多久 → `docs/handbook/group/chat-link.md`
  - 群里问题答得好不好、要不要沉淀 → quanttide-support 的支持章程
  - 编组、考核、转正、派驻职权 → quanttide-org 的 `orgs/qtacademy/institution/`
  - 起争议时的议事流程 → delib 议事契约

## 第一章 总纲（核心目标）

- 【已定】核心目标：在实训基地**模仿一个真实社区**，基地正式成员**模拟一家影子公司**（影子公司 = 模拟公司），一边培养、一边观察、一边考核
- 【已定·类比】公司 ≈ 内门弟子、实训基地 ≈ 外门弟子；进条款时还原成具体权利义务（哪件事谁说了算），不使用门派词
- 【待定】一句话可执行的总原则，不写哲学段（方向：每个群有人负责，每个问题有人接，每个承诺留痕）

## 第二章 群的设置

- 【已定】定位：实训基地的飞书社群，为课堂、众包、招聘三条线服务，是基地外围的社区组织
- 【已定】所有权：群归**公司**所有，不属任何个人
- 【已定】群主：**创始人**，且**群主不承担审批**——成员进出、招聘、考核一类的审批不在群主手里
- 【已定】管理员：公司与实训基地的管理人员；维护对象是**群公告、标签页**，让流程性工作在现有机制下解决
- 【已定】实际运营：由**实训基地正式成员**负责——日常运转的执行方，主要靠自治
- 【已定】群的性质：**候选池**——三类成员都在群内，是课堂录取、招聘录用、众包派单的候选来源；去留由流程决定，不由群内发言决定
- 【已定】基地与公司分工：招聘、考核等各方面由基地**初审**、公司**复审**，两条分开的流程，大部分事务直接交给基地负责（流程见 `docs/gallery/qtrecurit/index.md`：邮箱申请 → 群沟通 → 基地初审 → 公司复审）
- 【待定】除主群外是否另有部门群、项目组群、招聘群
- 【待定】群主 / 管理员 / 运营成员其余的具体动作：谁改公告、谁执行移出、离职与交接怎么办
- 【待定】机器人与自动化能做什么、不能做什么；什么情况建群、什么情况解散群

## 第三章 进群（准入）

- 【已定】**准入无门槛**：投递之后自动化处理，全程无人参与——案例见 `docs/gallery/qtrecurit/send-invite-email.md`（投递到 `hr@quanttide.com` → 自动回一封带群邀请链接的邀请邮件 → 点链接进群，状态「投递」→「邀请已发」）
- 【已定】进群这一环**不设审批**（无门槛即无审批；基地初审 / 公司复审发生在招聘与考核，不发生在进群）
- 【已定】成员三类来源：经**量潮课堂**加入的学生、经**量潮招聘**加入的申请者、**众包**参与者
- 【待定】三类同在一个群还是分群
- 【待定】管理方成员（管理员、运营成员）以什么身份在群内署名
- 【待定】进群第一件事：改备注（格式待定）、读公告
- 【待定】退出与清理：走第七章的自然淘汰，还是另有主动清退（如申请撤回）

## 第四章 群里怎么说话

- 【已定】功能：社区交流——公司及创始人在群内分享日常工作经验、成员提出问题、大家交流答疑
- 【已定】**管理员只答业务性的具体问题，不答流程性问题**；流程性问题由群公告、标签页等现有机制自行解决
- 【待定】提问的提法：一句话说清背景与诉求（这条直接决定支持成本）
- 【待定】公告与标签页：谁在什么时候更新，过期内容算谁的
- 【待定】禁止行为逐条列：广告拉人、绕过群的私聊施压、未脱敏的真名/客户信息外发、人身攻击
- 【待定】人转部门、项目组解散时群内怎么打招呼

## 第五章 问题的去处

- 【待定】业务问题谁应答、多久给第一次回应（异步优先，紧急才同步）
- 【待定】**流程性问题 / 业务问题的界线举例**——这条不写清，第四章的"只答业务问题"执行不了
- 【待定】答不了的升级给谁、怎么升（是否沿用基地初审 → 公司复审）
- 【待定】答过的往哪沉淀（问答库 / 案例记录）
- 【待定】哪些问题不在群里答：定价纠纷、未公开信息、个人考核争议

## 第六章 记录与留痕

- 【待定】群里的承诺与变更（时间、要求、结果）以什么形式留痕
- 【待定】案例出群：脱敏后才进 gallery / journal（真名→代号、链接剥离）
- 【待定】群记录留多久、谁有权翻

## 第七章 违规与处理（现状：自然淘汰）

- 【已定】**目前没有违规条款**，运转靠自然淘汰
- 【已定】自然淘汰 = 过一段时间不活跃即清理出群
- 【已定】具体的清理办法**不在本章程**，由基地成员自己制定
- 【待定】本章程要定的框架：清理的决定权在谁、多久评估一次、被清理者能否申诉
- 【待定】若日后出现违规行为（而不只是不活跃），处理顺序与执行人：提醒 → 群主约谈 → 移出群
